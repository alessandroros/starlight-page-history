starlight-page-history follows [semantic versioning](https://semver.org). While it is in `0.x`, a minor version may change behavior or options; the notes below say what to update. Patch versions only fix things.

Every version is on [npm](https://www.npmjs.com/package/starlight-page-history?activeTab=versions) and has a [GitHub release](https://github.com/alessandroros/starlight-page-history/releases). To hear about new ones, watch the repository and choose **Custom → Releases**.
