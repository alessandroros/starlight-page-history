Show every version of a [Starlight](https://starlight.astro.build) page and what changed, paragraph by paragraph, built from your Git history.

**📖 [Documentation](https://alessandroros.github.io/starlight-page-history/) · ✨ [Live demo](https://alessandroros.github.io/starlight-page-history/guides/demo/history/) · 📦 [npm](https://www.npmjs.com/package/starlight-page-history) · 📋 [Changelog](./packages/starlight-page-history/CHANGELOG.md)**

See the [package README](./packages/starlight-page-history/README.md) for features and the quick start.

## 📁 Repository

```text
packages/starlight-page-history/   the plugin: Git reader, diff, history page and footer link
docs/                              the documentation site, which is also the demo
```

## 🛠️ Develop

```sh
npm install
npm test        # unit tests
npm run dev     # the docs site, with the demo
```
