Compare any two versions of a page. A **Compare versions** box at the top of the history page diffs the two versions you pick, and **Compare with the latest** under each version compares it with the newest one. The comparison is kept in the address (`?from=…&to=…`), so it can be shared. Each page gets a `/<page>/history/versions.json` with its versions, loaded only when a reader compares.
